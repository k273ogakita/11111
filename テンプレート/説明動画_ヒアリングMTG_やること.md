# 説明動画 — ヒアリング／提案MTGのやること

病院・接骨院・その他、説明動画の打合せで毎回使うチェック。  
項目の中身（質問文）はその都度考える。**やることの型は同じ。**

正本の参照例：`営業/見込み客リスト/ゴキゲンホネグミ_*`  
ダッシュボード：動画案件の **商談フロー**（第一回ミーティング準備）

---

## 1. 目的・ゴールの整理

- [ ] 相手要望／動画の役割／今日の場のゴールを整理する

## 2. 当日台本作成

- [ ] **導入**（挨拶・ご縁へのお礼・自己紹介・今日のゴール先出し）
- [ ] **プラスアルファ提案を必ず入れる**（活用方法／見せる人のセリフなど）
- [ ] **活用の根拠**を用意（納得材料）
- [ ] **クロージング**：気持ちの確認・検討時の深掘り・その場で詰める流れ
- [ ] **クロージング**：次回ミーティング日時をその場で決める流れ

## 3. ヒアリングシート作成

- [ ] ヒアリングシートを作る（HTML・相手共有用／項目はその都度）
- [ ] 構成骨格はヒアリングで確認（その場で詰める前提で可）
- [ ] 打合せ後：記入済みをHTML保存して共有

## 4. プラン表の作成

- [ ] プラン表を用意（大まかで可／まだヒアリング段階・後出し用）
- [ ] Zoomリンクとミーティング日のアジェンダの送付

---

## 台本の必須ポイント（詳細）

1. **冒頭（導入）**  
   - 挨拶  
   - 「ご縁をいただきありがとうございます」  
   - 「せっかくのご縁ですので、私の自己紹介を少しさせてください」→ 気持ち・姿勢  
   - 「本日このようなお時間をいただきましたので、〇〇様にとって有意義なお時間になりますよう準備をしております。どうぞよろしくお願いいたします」  
   - **今日のゴールを先に伝える**

2. **中盤**  
   - ヒアリングシートに沿う  
   - プラスアルファ（活用方法／見せる人のセリフまで）  
   - 根拠で納得を厚くする  

3. **クロージング付近**  
   - 「本日このように話しました。〇〇様的にはいかがですか」を**必ず**聞く  
   - 「検討します」→「そうですよね。今のところ〇〇様的にはどう思われますか」  
   - 渋り →「どういう点が変わったら前向きですか」「具体的にどの点を検討されていますか」  
   - 「それがこうだとしたらどう思われますか」まで、その場で詰める  

4. **最後**  
   - 次回ミーティングの日程をその場で設定する
