## 私の強み（緒方・nARK）

個人の強みの正本（月次振り返り用）: `事業運営/緒方_強み.md`  
ここは患者説明動画の戦略向け要約。4つの重なり（市場／顧客／できること／提供価値）は正本側で振り返る。

### 一番の強み（本人の言葉ベース）

**① 看護師だから、伝わる・正確・伴走できる**

- 現役看護師として医療現場を理解している。**一言いただければ、言わなくても八割は汲み取れる**（やり取りが非常にスムーズ）
- その結果、**正確な説明動画**が短い打ち合わせで作れる
- 「作って終わり」ではなく、**寄り添って伴走**しながら、業務効率化と動画制作を一緒に進められる
- 他社（患者説明動画・医療系制作の競合）と比べたときの、**自分にしかない核**はここ

**② 個人でやっているから、柔軟・低コスト**

- 法人の制作会社より**柔軟に動ける**（要望・スケジュール・細かい調整）
- **コストを抑えて**提供できる（院長の予算感・フロント商品の価格帯と相性が良い）

## 競合分析・獲得見込み（社内メモ）

### 前提（2026-08-18 合同調査）— 以降の判断の出発点

以降の営業・LP・提案・ターゲット設計は、この前提を崩さない。

| 項目 | 内容 |
|------|------|
| 競合の売り方 | **動画単体ではなく、マーケティングツール・DXツールとセット**で売る会社が多い |
| 狙う院 | **「動画だけで十分」と思える医療機関**に絞る。ツール一式を欲しがる院は狙わない |
| もう一つの競合 | 会社に頼まず、**ツールを落として自分で動画を作る**院（内製・DIY） |
| nARKに頼む理由 | 自分で作る／ツールを契約するより、**時間・コストを抑えつつ高品質**になる |
| 価格の押し方 | 競合の月額と、nARKの**1本買い切り単価がほぼ同じ**なので、そこを強く推す |
| 競合に対して言えること | **価格競争力がある** |

**競合の価格帯（目安）**

| 帯 | 価格 | 見立て |
|----|------|--------|
| 中心帯 | **月額 ¥30,000〜 または ¥50,000〜** | 実務上の目安は **月額 3〜5万円** |
| 高額帯 | **月額 ¥350,000〜** | ツール一式・フルDX寄りのパッケージ |

**nARK側の対比（押し文句の核）**

- **単発発注ができる**（月額縛りではない。必要な本数だけ）
- **1年間の修正対応**がある（バージョンアップサポート・年額¥8,800〜）
- 競合は毎月 3〜5万円、nARKは **1本 ¥24,000〜（買い切り）＋任意サポート（1年目 ¥8,800／2年目以降 ¥4,400）** → 「月額と同じくらいの金額で、1本納品＋1年直せる」

### 総合判断

| 質問 | 結論 |
|------|------|
| 今の内容で競合に勝てる？ | **個人・歯科・開業〜開業後に絞れば設計は合理的。** 全国の冷たいリスト営業だけでの「総合勝ち」は、実績・サンプル前は早い |
| 案件獲得できる？ | **知人実績 → 事例公開 → 広告・フォーム**なら **月1本は射程**。チャネルより先に「見える化」が必要 |
| 最大のギャップ | 看護師×伴走は**言葉としては強い**が、見込み客から見える**証拠（サンプル・事例）がまだない** |

### 勝ちやすい／負けやすい

| 比較 | 判定 | 理由 |
|------|------|------|
| マーケ／DXツール付きの月額（3〜5万円） | ◎ 勝ちやすい | **動画だけで十分な院**に絞る。「月額と同じ金額で買い切り1本＋1年修正」が刺さる |
| 自分でツールを落として作る院 | ◎ 勝ちやすい | 頼むと**時間・コスト・品質**が揃う。内製の手間を買う |
| MEDIO（高単価オーダー） | ◎ 勝ちやすい | ¥3万・買い切り・短納期。「まず1本」ができる |
| 何もしない／YouTube流用 | ◎ 勝ちやすい | 自院名・自院の流れ・説明責任に合う |
| 一般の動画会社 | ◎ 勝ちやすい | 医療理解で打ち合わせ・修正が少ない（核となる強み） |
| 月額35万円〜のフルDX／ツール一式 | — 棲み分け | **動画以外も欲しい院はターゲット外** |
| S-QUE・TOPPAN | — 棲み分け | 大病院・高予算はターゲット外 |
| 「ブランドまで作り込みたい」院 | △ 負けやすい | カスタム範囲が物足りないと感じる場合がある |
| 実績・大手導入を重視する院 | △ 負けやすい | 事例・サンプルがない現段階 |
| 院内に既存ツールがある院 | △ 負けやすい | 乗り換えコスト＞メリットに感じやすい |
| フォーム営業のみの冷接触 | △ 負けやすい | 医療は信頼商品。文面だけでは弱い |

### 獲得が現実的な条件

1. 知人の医者・看護師経由で **最初の2〜3本**（信頼＋実績）
2. 実績を載せたうえで **検索広告（月¥1万〜）＋フォーム営業**
3. **月1本** は上記が回れば十分射程

※ テンプレ未完成・事例ゼロのまま広告・フォームだけ → **厳しい**。フロントは件数優先だが、**最初の数件は「見える化」への投資**と捉える。

## 見込み客視点（院長・クリニックが買う理由）

### 院長の頭の中（典型）

> 「説明動画は欲しい。でも時間がない。変な会社は怖い。安いのは不安。うち向きかわからない。」

### 今のサービスが刺さるポイント

| 不安・欲求 | 刺さる要素 |
|-----------|-----------|
| 時間がない | 一言で八割理解・短納期・打ち合わせ少 |
| うち向きか不安 | カテゴリ選択・ロゴ差し替え（※サンプルがあればさらに強い） |
| 安いけど大丈夫？ | 看護師・バージョンアップサポート・買い切り永続 |

### 刺さりにくい訴求

- 「最高のクオリティ」だけ（テンプレ商品と矛盾）
- 「他院と同じでいい」だけ（差別化にならない）

### 院長向けの競合比較トーク

| 院長の選択肢 | 向いている人 | nARKの一言 |
|-------------|-------------|-----------|
| マーケ／DXツールの月額（3〜5万円） | 動画以外の機能は要らない | 「毎月払う金額で、1本納品できます。単発で頼めます。1年直せます」 |
| 自分でツールを落として作る | 時間がない／品質が不安 | 「頼むと、時間もコストも抑えつつ、高品質になります」 |
| 高いオーダー制作（MEDIO等） | ブランドにこだわる | 「まず院内で回す1本」を安く早く |
| 何もしない | 説明に時間をかけている | 院長の時間を買うサービス |
| 汎用制作会社 | 修正に疲れた経験がある | 看護師が一言から作る。打ち合わせが少ない |
| 月額35万円〜のツール一式 | DXまで一気に入れたい | 棲み分け（狙わない） |
